In the `.env` file are available the following variables:

ENVIRONMENT - The current environment: `development` or `production`.

MAIL_SERVICE - MAILJET.
MAILJET_FROM - The email that will send the email.
MAILJET_HOST - The mailjet host.
MAILJET_PORT - The mailjet port.
MAILJET_API_KEY - The mailjet api key.
MAILJET_API_SECRET - The mailjet api secret.

IDENTIFY_SALT - The hash salt.
